# 站点其余页面设计评审与修改意见

> 评审范围：v0.10.0 基线（restore-polished-ui）上，除 主页 / 博客 / 日记 / 知识库 / 精读 之外的全部页面
> 参照系：`博客设计复盘与开工清单.md` 的构图契约 + 已完成的五个成品房间语言
> 截图存档：`AI-frontend/qa-reports/page-review-20260912/`（qa-reports 已 gitignore，仅本地）
> 日期：2026-09-12 · 评审方式：1920×1080 视口逐页实拍（qa-designer / administrator 登录态）

## 0. 成品房间的「基准语言」（评审依据）

看完五个成品页，站点的视觉宪法已经很清晰，其余页面照此归位即可：

| 层 | 约定 |
|----|------|
| 舞台 | 1920×1080 车站舞台；点阵 + 径向雾背景；**晨/午/暮/夜时段氛围**联动全站色温 |
| 壳 | 公开房间 = 站点顶栏（品牌 + 房间导航 + 时钟 + 头像）+ 玻璃卡三栏（side 248 / main / deck 300）；后台 = 夜航工作台壳（左图标栏） |
| 房间色 | 博客=樱粉 Vol 杂志 · 日记=lilac 手账 · 知识库=蓝图书馆 · 精读=紫罗兰天文台 · 音乐=Pulse 舞台 |
| 字体 | 展示字 ZCOOL KuaiLe 只用于标题/eyebrow；正文禁用展示字 |
| 装饰 | 每页必有：舞台氛围 + 房间道具 + **右栏戏份（禁止空 deck）** + 入场动效（prefers-reduced-motion 收） |
| 硬约束 | 禁通栏长条、禁大色块、禁 emoji 当图标、禁居中瘦卡两侧真空、占位图写 `[image] 比例` |

## 1. 全站通用问题（先修，收益最大）

### P1-1 · 「该功能未启用或不存在」toast 侵染
工作日志（×3）、个人信息（×1）、精读-文章列表（×2）一进页面就弹报错 toast，堆在顶栏上，第一印象极差。
**意见**：逐个排查来源接口（疑似 worklog 云同步、EchoBot 桌宠绑定、精读学习相关）。后端确实没有的，前端对 40400/功能未启用**静默降级**为页内空态文案（如「云端同步未启用，仅本地记录」）；后端应有的，补路由。任何页面不允许加载时无解释的报错弹层。

### P1-2 · 三种壳并存且归属不清
公开房间=站点壳；用户管理/应用管理/博客管理/对话管理/个人页=夜航工作台壳；**站点设置却用公开亮色壳**；精读-采集=工作台壳而精读-文章/学习=公开壳。
**意见**：定一条规则——`workspaceMeta`（需登录的操作台）一律夜航工作台壳，`publicMeta` 一律站点壳；当前 settings 用公开壳、精读文章用公开壳都属于规则外的例外，要么改 meta 要么书面确认为「故意」。壳的视觉（左栏选中态、面包屑）也要统一。

### P1-3 · 工作台壳缺身份与时段联动
左栏是裸 icon 列表：无分组、无 hover 名称、当前页无强调色标记（只有设置 icon 常亮紫）、且固定深夜色不跟时段。
**意见**：icon 加 hover 气泡名称与当前页描边（用所在房间强调色）；夜色保留但把时段 hue 映射到左栏选中态与页面 accent 上（精读采集页的暖橙就是正确示范）。

## 2. 逐页意见

### 2.1 工作日志 `/worklog` —— P1 整改（问题最多的一页）

**现状**：加载即 3 个报错 toast；四条全宽统计条占掉半屏（通栏忌讳）；薄荷绿大色块按钮偏离站内色板；无三栏壳、无右栏、无房间道具；编辑器被挤到页面底部；下方大片真空。
**房间定位建议**：「考勤打卡机 × 工程师手账」。
- 左栏：关于 + **连续打卡印章卡**（连续天数做成日式打卡章，随连续天数换涂层）+ 本月热点词做成和纸标签。
- 主栏：**今日编辑器当主角**（玻璃卡 + 手账纸质感，对齐日记的正文纸语言），历史归档收进右栏或抽屉。
- 右栏 deck：本周摘要「周报杂志卡」+ 导出 MD/同步包做成贴纸按钮组 + 备份提醒改为**和纸胶带便签**贴在卡上（别再占通栏）。
- 色彩：薄荷绿可保留为房间第三强调色（站内已有 lilac/blue 先例），但调成站内薄荷 `#a8e6cf` 系并只用于描边/标签/按钮描边，禁大色块填充。
- 统计四条改成一行紧凑玻璃芯片（数字用 tabular-nums）。

### 2.2 实验室 `/lab` —— P1 整改

**现状**：居中一张瘦卡 + 两侧大片真空（自查句：这就是清单里点名的「一条被拉长的后台表格」反面教材）；「我的小实验」空态平淡；快速提示是裸文本 chip。
**房间定位建议**：「实验台 + 试管架 + 样品瓶」。
- 左栏：关于 + 实验安全须知（趣味文案）+ 生成历史时间线。
- 主栏：生成台做成「试剂调配单」（目标输入 + 类型选择 + 快捷提示做成**试剂标签**可点注入）；我的实验改成 bento 样品瓶网格——每瓶=封面 `[image] 3:4` + 状态珠（生成中=冒泡烧瓶动画）+ 名称 + 日期。
- 右栏 deck：灵感试纸架（快速提示卡，点击直接注入输入台）+ 最近部署的应用卡（appController 数据现成）。
- 标题排版对齐博客/日记：左对齐 eyebrow + 大标题，别居中。

### 2.3 对话 `/chat` —— P1 整改

**现状**：居中一张卡（select + textarea + 按钮），整页真空；select 显示裸角色 id「dny」；看不到历史会话与角色差异。
**房间定位建议**：「通讯交换台 / 话务室」。
- 主栏：**AI 角色做成玻璃名片墙**（头像 `[image] 1:1` + 名字 + 一句话人设；选中态描边房间色），下方输入台；角色 select 仅作为降级控件且必须显示角色名。
- 右栏 deck：最近对话列表（真实 conversationId，可续聊/删除）+ 本周对话数小统计。
- 左栏：关于 + 使用提示。
- 交互契约：Enter 发送、Esc 回首页、深链 `/chat/:id` 续聊。

### 2.4 音乐 `/music` —— ✅ P0 已修复（2026-09-12）

**原状**：主站 dev 模式下整页是 Vite 编译错误浮层：`virtual:pwa-register` 只在 music-standalone 构建模式注册，而 dev 下访问 /music 会按「同名 html 兜底」规则命中根目录 `music.html`（独立播放器入口），导致解析失败。顶栏「音乐」=死链。
**修复**：新增 `src/pwa-register-stub.ts`（registerSW 空实现），`vite.config.ts` 仅在**非 standalone 模式**把它别名到 `virtual:pwa-register`；standalone 构建仍用插件真实现。dev 与 prod 的 /music 现在都渲染完整的 MIKU PULSE 播放器（`MusicPage`，独立版 `MusicStandaloneApp` 只是它的 7 行壳）。
**备注**：本地播放/搜索需要 `netease-api`(3000) 与 `meting-api`(3300) 两个代理服务在线；不带服务时页面照常渲染，只是没有曲目来源。原「舞台前厅」轻量改版建议按用户决定**不再执行**——保留完整版播放器。

### 2.5 关于 `/about` —— P2 风格归位

**现状**：全屏动漫壁纸 + 暗色玻璃卡，完全脱离站点语言；顶栏链接压图不可读；无时段氛围。
**意见（倾向 A）**：
- A：套 StationRoomShell 做「站长工作台」三栏——左=技能贴纸墙；中=自我介绍手账页（头像+简介+项目时间线）；右=联系名片（邮箱/GitHub 名片卡）+建站日志。
- B（若要保留壁纸特色页）：至少加顶栏可读性遮罩、玻璃卡换站内 ink/paper 色、chips 对齐站内 tag token、时段联动换图。

### 2.6 个人信息 `/user/profile` —— P2

**现状**：工作台壳但内容是原始表格；创建时间显示裸 ISO（`2026-09-12T17:18:53`）；进页报错 toast；EchoBot 空态是灰色通用插画。
**意见**：
- 信息卡改「**站员证/登机牌**」：大头像 + 账号 + 角色徽章（角色色入 token：管理员 violet / 用户 mint）+ 入站日期中文格式。
- 表格改两列描述卡；「修改信息」用弹层/抽屉。
- EchoBot 区改「**设备架**」：已绑定=设备卡（名称+时间+解除），空态=站内线稿风格插画+「还没有设备登车」。
- 修掉报错 toast（同全站 P1-1）。
- 可与 Miku 桌宠联动：绑定成功后桌宠气泡提示。

### 2.7 后台管理四页 `/admin/userManage · appManage · blogManage · chatHistoryManage` —— P2 整组统一

**现状**：夜航壳 + 原始 ant 表；**整表都在用 ZCOOL KuaiLe 展示字体**（数据/ID/日期可读性差）；长雪花 ID 原样折三行；头像列是暗色空方块；chatHistoryManage 每行红字「清空对话」一触即达（危险操作无层级）；表格下方大片真空；blogManage 表内有一条游离竖线。
**意见（整组一次改）**：
- 表格正文字体换站内正文体；展示字只留页面标题；数字列 `tabular-nums`。
- ID 列截断 `前6…后4` + hover 全量 + 复制按钮。
- 头像空值用站内默认占位（圆角+首字），不留暗块。
- 危险操作收进「···」菜单 + 二次确认；行内只留安全操作（编辑/发布）。
- **真空右移**：每页加右栏 deck——用户页=角色分布/今日新增统计卡；博客页=各状态文章数+近七天发布小柱阵；对话页=消息类型占比+活跃应用 Top5。对齐「右栏不许空」的房间规则。
- 空态插画换站内线稿风（如空档案柜），配站内语气文案。
- 修掉 blogManage 表内游离竖线。

### 2.8 站点设置 `/admin/settings/site` —— P2 小修

**现状**：亮色站点壳 + 左模块列表（P0-P4 徽章）+ 表单，观感尚可；但输入框横贯 1920（通栏输入忌讳）；保存/恢复默认是全宽暗色大条。
**意见**：表单主栏限可读宽度（≈720px），右侧加 deck：模块概览（当前开启 N/M）、最近修改（链到 audit）、集成健康入口；按钮组改贴纸风小按钮。壳归属问题按 P1-2 的规则定。

### 2.9 登录 / 注册 `/user/login · /user/register` —— P3 打磨

**现状**：已套站壳，观感不错。
**小修**：「Station · 入站/登记」虚线胶带悬在左上角与内容无关，改为贴在玻璃卡上沿的斜角胶带；左侧欢迎文案与右侧卡片基线脱节，可加一条进站引导虚线把视线引向卡片。其余保持。

### 2.10 模块未开放 `/module-unavailable` —— P3

**现状**：还原后已达标（警告卡 + 返回首页）。
**小修**：加「返回上一页」次按钮；模块名旁可用对应房间色的圆点提示（哪个房间没开门）。
